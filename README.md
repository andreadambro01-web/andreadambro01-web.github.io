# Portfolio HTML, CSS & SCSS - Andrea D'Ambrosio

Questo è il mio sito personale realizzato per il corso Start2Impact.
Il progetto è stato sviluppato con particolare attenzione alla struttura, alla responsività e all’organizzazione del codice tramite SCSS.

---

## Struttura del progetto

- `index.html` → Home page con presentazione personale e progetti
- `cv.html` → Curriculum Vitae in formato HTML
- `contatti.html` → Pagina contatti con form di invio messaggi
- `src/scss/` → Codice sorgente SCSS organizzato secondo il pattern 7-1
- `dist/css/style.css` → File CSS compilato da SCSS
- `assets/images/` → Immagini del sito e dei progetti
- `assets/favicons/` → Favicon del sito

---

- HTML5

## Funzionalità

- Layout completamente responsive
- Navigazione sticky con menu hamburger su dispositivi mobili
- Struttura SCSS modulare basata sul pattern 7-1
- Utilizzo di variabili, mixin e funzioni SCSS
- Form di contatto funzionante con invio email tramite EmailJS
- Hero section responsive
- Cards progetto responsive
- Footer sticky
- Meta tag SEO base
- Favicon personalizzata

---

## Obiettivi del progetto

Il progetto ha lo scopo di dimostrare la capacità di:

- strutturare un sito multi-pagina
- organizzare il codice CSS tramite SCSS
- utilizzare HTML semantico
- realizzare layout moderni e responsive
- creare componenti riutilizzabili
- gestire un progetto frontend strutturato
- utilizzare Git e GitHub per il versionamento

---

## Responsive Design

Il sito è ottimizzato per:

- smartphone
- tablet
- desktop

Il menu di navigazione si trasforma automaticamente in hamburger menu sui dispositivi mobili.
